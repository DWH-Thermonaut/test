    Was bedeutet das Ergebnis?

    • Erfolgreich / lesbar: Der Server erlaubt den Cross-Origin-Zugriff und JavaScript kann den Antworttext lesen.
    • Failed to fetch / CORS-Fehler: Der Browser hat den Abruf blockiert. Häufig fehlt Access-Control-Allow-Origin, es gibt einen TLS-/Netzwerkfehler oder eine Weiterleitung auf eine nicht erlaubte Adresse.
    • no-cors / opaque: Der Request kann eventuell gesendet werden, aber JavaScript darf Status, Header und Inhalt ausdrücklich nicht lesen. Das ist kein CORS-Bypass.
    • Header: JavaScript darf nur bestimmte Response-Header sehen. Nicht sichtbare Header werden hier nicht angezeigt.

    Dieses Tool kann CORS nicht umgehen und kann bei einem blockierten Abruf den Quelltext nicht auslesen. Dafür wäre ein eigener Server-Proxy nötig, der die Zielseite serverseitig abruft und den Zugriff kontrolliert freigibt.
